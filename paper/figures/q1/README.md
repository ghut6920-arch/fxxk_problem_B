# 问题一图表交付

本目录按用户提供的《问题一图表方案：最终执行版》V1.0 生成问题一的两幅正文图与附表 A1。固定方案文件的 SHA-256 为 `6030ba66ee03a9a818f65b04c991238079c0540b945d3696b97615514265a53e`。

## 文件

- `generate_q1_figures.py`：确定性绘图与几何验收脚本。
- `data/`：执行包中两份 JSON 取数入口的逐字节副本；它们是派生绘图输入，不是官方数据。
- `source_packet/`：最终执行方案、清单与原包数据核验记录的逐字节副本，用于追溯；不视为官方证据。
- `output/Q1_Fig1_Intersection_Diameter.*`：图 1 的 PDF、SVG 和 600 dpi PNG。
- `output/Q1_Fig2_Diameter_Coverage.*`：图 2 的 PDF、SVG 和 600 dpi PNG。
- `output/Q1_Figure_Validation.json`：输入哈希、几何检查、运行环境与输出哈希。
- `Q1_TableA1_Boundary_Cases.md`：可编辑附表。

## 生成

在本目录运行：

```powershell
python .\generate_q1_figures.py
```

脚本先验证输入哈希与固定几何关系，再写出图件；任一检查失败时停止输出。

## 正文引用句与图注

图 1 正文引用句：

> 如图 1 所示，各次带误差的示向观测形成向前楔形，其公共部分构成定位区域。对非空有界的多边形区域，比较有限顶点对的距离即可确定区域直径。

图 1 图注：

> 图 1　交会定位区域及其直径计算。(a) 三个检测点的示向度分别生成半角为 1° 的向前楔形，其交集为方向定位区域 P。(b) 对同一区域局部放大，AB 为最远顶点对，区域直径约为 27.68 m。坐标单位为米。所示观测为自构确定性算例，顶点与直径由普通双精度几何核算得到，用于说明算法。

图 2 正文引用句：

> 图 2 在相同直径和显示尺度下比较两类三角形。直角等腰三角形可被同直径圆覆盖，而等边三角形不能；后者的最小覆盖半径为 $D_P/\sqrt{3}$，严格大于 $D_P/2$。

图 2 图注：

> 图 2　相同区域直径下的圆覆盖对照。各面板按 $D_P$ 归一化，使用相同端点 A、B 和显示尺度。(a) 直角等腰三角形可由以 AB 为直径的圆覆盖。(b) 等边三角形具有相同直径，但顶点 C 位于该圆外；任何半径为 $D_P/2$ 且同时包含 A、B 的圆，其圆心必须为 O，故改变圆心不能消除该反例。(c) 该等边三角形的最小覆盖圆圆心为 J，半径为 $D_P/\sqrt{3}$。各图均为解析几何构造。
