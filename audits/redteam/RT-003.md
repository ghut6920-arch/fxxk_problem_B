## Findings and Counterexamples

### RT3-F1 — Closed directional boundary rejected

- Severity: `MAJOR`.
- Evidence: plan §2 is `n(φ)ᵀ(p-g) ≥ 0` (closed). `predicates.visibility` at `a49cc648` uses `cos/sin` floats with no exact-rational or algebraic cross-check (EXP-002 SPEC evaluator-only requirement).
- Minimal counterexample A: `g=(700,700)`, `φ=90°`, `R_c=1500`, `p=(0,700)` (a `P_4` point). Exact normal `(0,1)`, dot product `0`, `r=700` → expected `direction`. `cos(π/2)=6.123e-17`, float dot `-4.286e-14` → actual `visibility=False`, `observation='no_signal'`.
- Minimal counterexample B (not in TR-012): `p=(0,0)`, `g=(1,1)`, `φ=135°`. Analytic dot product `0`. Float dot `-1.11e-16` → `vis=False`. Same geometry at `φ=-45°` yields float dot `0.0` → `True`.
- Expected: closed-boundary points are visible. Actual: sign of the trigonometric residue decides the official predicate.
- Affected claim or component: observation oracle for G14/G15/T03 and any later candidate scoring on directional boundaries. Implementation defect, not a model-family failure.
- Required remediation: exact 90° normals and/or the algebraic form `|wrap(φ-arg(g-p))| ≥ 90°`; regressions for `(0,700)`, `(1400,700)`, and `φ=135°`. Do not widen official visibility with a loose tolerance.

### RT3-F2 — Finite expectation matches NaN

- Severity: `MAJOR`.
- Evidence: `selfcheck.compare` uses `abs(float(expected)-float(actual)) > tol`. `abs(1.0 - nan) > 1e-9` is `False`.
- Minimal counterexample: `compare(1.0, float('nan'))` → `[]`. Same for `[1.0, 2.0]` vs `[1.0, nan]` and `{'r': 1.0}` vs `{'r': nan}`. `compare(1.0, inf)` does fail. Extra actual keys are ignored: `compare({'a': 1.0}, {'a': 1.0, 'b': float('nan')})` → `[]`.
- Expected: a finite number does not match NaN. Actual: empty mismatch list (pass).
- Affected claim or component: the only `evaluator_now` numeric gate. Current frozen fixtures are finite, so the suite does not exercise this hole; a NaN covering-circle or diameter would still match a finite expectation.
- Required remediation: reject NaN vs non-NaN and mismatched infinities; fail on unexpected nonfinite extra keys; add NaN regressions.

### RT3-F3 — G07b labelled `NUMERICAL_UNCERTAIN` while unboundedness is certifiable

- Evidence: catalog G07b is conditional (“if a finite vertex set cannot be certified”). Frozen `G07.json` and `halfplane.near_collinear_wedges_state` treat a 1° feedback-bin gap (design §4.3) as a geometric precision limit. - Minimal counterexample: frozen `S1=(0,0)`, `θ̂₁=0°`, `S2=(1000,0)`, `θ̂₂=0.01°`, `δ=1°`. Point `q=(2000,0)` and ray `q+t(1,0)` (`t≥0`) satisfy both direction contracts.
