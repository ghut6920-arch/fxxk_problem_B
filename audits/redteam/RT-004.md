### RT4-F2 — `build_outer` is NameError-dead

- Severity: `MINOR`.
- Evidence: `src/candidate/cells.py` `build_outer(..., max_depth=MAX_DEPTH)` calls `state.apply(feedback, max_splits)` with `max_splits` unbound. Independent call raises `NameError: name 'max_splits' is not defined`. No test calls it; `OuterState.apply` used by T05 is intact.
- Expected: helper matches `apply` signature or is removed.
- Actual: unusable helper left in the candidate package.
- Affected claim: none of the named G/T properties if callers use `OuterState` directly.
- Required remediation: pass `max_splits=None` or delete the helper.

### RT4-F3 — `L=2` gate is not consulted by `C0Runner`

- Severity: `MINOR`.
- Evidence: `AdaptiveGate` correctly keeps count on ordinary feedback / region shrink / channel switch and forces fallback at count 2 (independent). `C0Runner` stores `self.gate = AdaptiveGate()` but `run_scan` / `run_clears` never call `on_adaptive_action`, `on_ordinary_feedback`, or `must_fallback`.
- Expected: T08 property on the scheduler object; C0 has no adaptive actions, so an unused gate is consistent with C0-only scope **if** later adaptive hooks cannot skip it.
- Actual: unit-level T08 holds; runner integration is absent.
- Affected claim: T08 `candidate_later` if scored only through `C0Runner` without going through `AdaptiveGate`.
- Required remediation: either document that C0 never takes adaptive actions, or consult the gate before any adaptive step.
