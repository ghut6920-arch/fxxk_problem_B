# 候选比较与后续优先顺序

工作项：[WI-009](../work/WI-009.md)。详细算法与证据表见[完整数学方案](COMPLETE_MODEL_PLAN.md)，三候选见[CANDIDATE_MODELS](CANDIDATE_MODELS.md)。本次没有最终选型或性能排名。

## 共同标准

所有路线使用同一官方规则、相同的信息边界、全部清除要求和完整虚拟成本账本。现实时间另外约束，实验表现不能替代连续空间证明，数学条件也不能替代实现验证。类型和返回精度的依据以修订后的[RULES](../problem/RULES.md)为准。

| 维度 | C0 | C1 | C2 |
|---|---|---|---|
| 确定内容 | 两套固定扫描、225点局部清除、完整账本 | 有限外包、固定L、公平队列、全反馈预算检查 | 反馈树形式与可引用的后备终端界 |
| 发现/清除保证来源 | 连续检测与清除覆盖 | C0后备、真值包含和有限进展 | 同C1，另需分支和界的正确性 |
| 虚拟预算 | 给出完整C0解析上界 | 保留可执行后备证书，不满足则后备 | 由终端界及各分支约束保护 |
| 现实可行性 | 未验证 | 未取得现实上界前不启用自适应 | 未验证 |
| 计算风险 | 固定动作较简单，请求数较多 | 外包粒度、反馈求值与评分退化 | 树规模与上下界松紧 |
| 当前性能数据 | 无 | 无 | 无 |

Q3与Q4分别构造网格可避免全向问使用不必要的强定向条件。C0的虚拟上界不是实测耗时；C1计算较复杂不意味着一定更慢，也不意味着一定减少总任务时间。

## 推荐依赖顺序

先获取C0参考算法的实现正确性和现实调用时间证据，因为C1/C2的保证依赖它；随后优先验证C1是否带来实际增益。C1仍是优先关注的自适应候选，C2保留为拓展。这是验证依赖顺序，不是批准进入实验，也不是最终主模型选择。

C1本来就是“确定后备加自适应”结构。本轮将其具体化，而不是借外部审计暗中更换模型族。经验平均评分可在未来有可靠数据时另行提出；现在继续使用无概率先验的参考评分并明确可能退化为C0。

## 外部审计意见的处置

- 采纳：原题支持Q4两类都存在；返回值按1度合同；补虚拟100小时规则；补Q2有限算法；补C0完整清除、有限外包、公平队列及预算证书。
- 部分采纳：交会角解释有益，但90度不是改变距离和移动成本后的无条件最优；Q3/Q4网格分开属于有效优化构造，共用密网格原本不构成数学错误。
- 保持已有解释：Q2 near评分0不表示精确位置，覆盖半径作为目标是合理自主选择；没有依据强制改成直径唯一主指标。
- 不采纳为当前结论：经验分布、C1必然更快、C2已经不可行、审计分数或“可进入论文”代表正式批准。

## 需要讨论或取得后续证据的事项

1. 保守区间与提交坐标偏差认证能否在实际软件中正确实现。
2. Q2的候选和上界粒度是否足以改善定位；未认证质量不等于不存在更好测点。
3. C0请求数、重试、计算开销与实际剩余现实窗口是否相容。
4. C1在公平和预算条件下是否有足够正分动作，实际收益是否抵消计算成本。
5. 现实资源上界如何取得证据；不能用少量延迟样例声称任意网络最坏保证。
6. C2是否存在足以支持额外复杂度的多步收益证据。
